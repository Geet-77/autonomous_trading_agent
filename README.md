An autonomous AI-driven trading simulation script developed as a software engineering project during my first year at COEP Technological University. This project serves as an initial exploration into parsing historical market feeds, and algorithmic decision-making loops using Python.

## 🚀 Project Overview
The objective of this project was to design an isolated simulation environment where an automated agent could evaluate market conditions and execute simulated trade directives without human intervention. 

- **Language:** Python 3.x
- **Core Architecture:** Single-agent state-machine logic (`agent.py`)
- **Primary Focus:** Dynamic boundary testing, API/data handling, and logic routing.
